DEV-03 + DEV-04: migrations, seed and verification harness

db/migrations/001_initial.sql: 5 subject tables (shelters, accounts,
needs, offers, deliveries), 5 supporting indexes per doc 03 §4, and
the need_balances view per doc 03 §5 (CROSS JOIN LATERAL).

db/migrations/002_auth_sessions.sql: auth_sessions table per
doc 04 §3.2 with SHA-256 id_hash, csrf_token, expires_at, revoked_at
plus 2 supporting indexes.

scripts/migrate.mjs: real runner. Reads db/migrations/*.sql in lexical
order; tracks applied files in schema_migrations(name, checksum,
applied_at) with FNV-1a checksum. Each migration runs in its own
transaction.

scripts/seed.mjs: idempotent demo seed. Reads db/seed/data.mjs,
Argon2id-hashes passwords read from DEMO_*_PASSWORD env vars, then
ON CONFLICT (id) DO UPDATE for shelters / needs / accounts.
--reset flag truncates subject tables.

db/seed/data.mjs: 3 shelters (Добрые лапы / Приют Северный /
Спасение на юге), 10 needs (urgent + normal; categories food,
hygiene, textile, equipment, carriers, other), 4 accounts (admin +
rep_a/b/c with shelter_id FK).

scripts/verify-schema.mjs: dump tables / migrations / views /
need_balances columns.
scripts/verify-encoding.mjs: assert server_encoding = UTF8 and a
Russian text roundtrip.
scripts/verify-seed.mjs: dump seed and verify admin Argon2id hash.

scripts/start-pg.mjs: idem-potентный init (PG_VERSION probe);
initdbFlags = ['--no-locale', '--encoding=UTF8'] to avoid Windows
WIN1252 default that broke Cyrillic storage.

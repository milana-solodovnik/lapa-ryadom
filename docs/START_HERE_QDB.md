# Что делать прямо сейчас: получить Digital Q.DataBase

**Одна задача, ~10 минут. Сделает Евгений, потому что нужны его личные данные.**

---

## Шаг 1. Открой ссылку

**https://catalog.diasoft.ru/database**

Это официальная страница загрузки СУБД Digital Q.DataBase от компании «Диасофт».

Если не открывается — вот запасная: **https://database.diasoft.ru/** и на ней кнопка «Скачать бесплатно».

## Шаг 2. Заполни форму

На странице есть форма. Поля:

| Поле | Что вписать |
|---|---|
| Имя и фамилия | твои реальные данные |
| Должность | например «Студент» или «Разработчик» |
| Организация | название вуза / компании |
| Email | **почта, к которой у тебя есть доступ** |
| Мобильный телефон | в формате +7... |
| ☐ Согласие на обработку персональных данных | **обязательно поставить галочку** |
| ☐ Согласие на рассылку | необязательно, можно не ставить |

Нажми **«Отправить»**.

## Шаг 3. Жди письмо 5–10 минут

На почту придёт ссылка на скачивание. **Обязательно проверь папку «Спам»** — там она чаще всего.

Если письма нет через 15 минут: проверь, что адрес в форме написан без опечаток, и напиши на **dbd@diasoft.ru**.

## Шаг 4. Скачай архив

В письме будет архив примерно **1,5 ГБ**. Скачай его и **ничего не распаковывай пока**.

Положи файл в папку: **`F:\MVP\hakaton\infra\qdb-dist\`**

(Папку создай сам, если её нет. В `.gitignore` она уже добавлена, в репозиторий не попадёт.)

Внутри архива ищи файл вида:
```
docker-qdatabase64xid-17-17.4.xxxxxxxx-ubuntu22_x86_64.tar.gz
```

## Шаг 5. Напиши мне «готово»

Дальше я сделаю всё сам, без дополнительных вопросов:

1. `docker load` — загружу образ
2. `docker run` — запущу контейнер с портами 5445 / 1433 / 1521
3. Правка `pg_hba.conf` + перезапуск — разрешу внешние подключения
4. **QDB-02** — сниму `SELECT version()` и параметры сборки
5. **QDB-03** — прогоню 15 проверок совместимости PostgreSQL
6. **QDB-04** — применю миграции и перенесу данные одной транзакцией
7. **QDB-05** — сверю строки, ключи, времена, FK и балансы

## ⚠️ Важно про WSL2

Docker Desktop **уже установлен** (версия 4.96.0). Но на этой машине нет WSL2, а без него
Linux-контейнеры не запустятся.

Когда скачаешь архив, я спрошу ещё раз: ставить WSL2 с перезагрузкой (официальный быстрый
старт, 4 команды) или разворачивать из установщика Windows без перезагрузки.

Виртуализация в BIOS у машины включена — проверено, так что установка WSL2 должна пройти.
